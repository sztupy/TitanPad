# Example Configurations

You can find some example configurations on this page.

## List

* [Gamepad Emulation in Dolphin](./Dolphin.json) Analog Joystick setup to be used within Dolphin Emulator. Also see [the tutorial video](https://www.youtube.com/watch?v=KmtyBWD3xmQ)
* [Scroll Mouse setup in Termux/X11](./X11.json) Mouse and mouse scroll setup to be used within Termux/X11. Also see [the tutorial video](https://www.youtube.com/watch?v=akeR65n24pI)

## Contribute

Feel free to create pull requests that add new example configs. Please update the list above as well with a short description.
